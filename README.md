# 🍰 تطبيق لقمة و بسبوسة (بسنت)
تطبيق ويب متكامل (PWA) لإدارة وعرض منتجات متجر حلويات، يشمل واجهة للعملاء ولوحة تحكم متكاملة للمسؤولين.

## 🛠️ التقنيات المستخدمة (Tech Stack)
* **HTML5 & CSS3:** لبناء الهيكل وتنسيق الواجهات.
* **Tailwind CSS:** مكتبة تنسيقات لبناء واجهة لوحة التحكم بشكل متجاوب وسريع.
* **Vanilla JavaScript (ES6+):** برمجة المنطق بالكامل (Logic) والتفاعل مع الواجهات (DOM Manipulation).
* **Firebase Cloud Firestore:** قاعدة بيانات (NoSQL) لحفظ المنتجات، الأقسام، العروض، بيانات العملاء، وتاريخ الطلبات في الوقت الفعلي (Real-time).
* **Firebase Authentication:** نظام حماية للوحة التحكم لضمان أمان البيانات.
* **PWA (Progressive Web App):** استخدام `manifest.json` و `sw.js` (Service Worker) لدعم التخزين المؤقت (Caching) وإمكانية تثبيت الموقع كتطبيق على الهواتف.
* **Local Storage:** ذاكرة المتصفح المؤقتة للاحتفاظ بجلسة العميل (رقم الهاتف) لعدم إجباره على تسجيل الدخول في كل زيارة.

## 💡 كيف يعمل نظام العملاء (Accounts System)؟
النظام لا يعتمد على كلمات مرور معقدة للعملاء لسهولة الاستخدام:
1. **قاعدة البيانات (Firebase):** هي الخزنة الرئيسية التي تحتفظ بكل تفاصيل العميل (النقاط، سجل الطلبات، العنوان).
2. **الذاكرة المحلية (LocalStorage):** تعمل بمثابة "مفتاح" للعميل (تحتفظ برقم الهاتف). عند فتح التطبيق، يتم قراءة الرقم وسحب أحدث البيانات أوتوماتيكياً من Firebase في الخلفية (Background Sync).
3. **إرسال الطلبات:** يتم معالجة سلة المشتريات (Cart)، وتجميع الإجمالي وإضافة مصاريف الشحن، ثم تُرسل تفاصيل الطلب منسقة عبر WhatsApp، مع تسجيل الطلب فوراً في قاعدة بيانات العميل وتحديث نقاط المكافآت.
